# HKBU Research Gate Catalog Description

A clean, structured catalog and control guide outlining public library research tools, institutional authentication requirements, and access pathways for Hong Kong Baptist University (HKBU) resources.

## Overview

This repository serves as a reference directory for academic and research tools available through the HKBU library ecosystem, categorized by access type and function:

* **Library AI & Synthesis:** [LeapSpace](https://cedar-ever-grove-lagoon.grok.me/), [Consensus](https://cedar-ever-grove-lagoon.grok.me/), and [scite](https://cedar-ever-grove-lagoon.grok.me/) integration guidelines.
* **Access & Authentication:** OpenAthens SSO configurations and institutional credential protocols.
* **Data & Quantitative Tools:** Research Data Services, CSDI stations, and citation management systems (EndNote).
* **Open Exploration:** Guidance on open scholarly tools (Elicit, Connected Papers, Research Rabbit) and compliance guardrails.

## Usage & Compliance
Designed to provide transparent access notes regarding institutional subscriptions, ensuring proper handling of licensed full texts and adherence to academic integrity guidelines.
